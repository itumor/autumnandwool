# Content usage-rights request: DRAFT (PAR-12)

Status: DRAFT. Not legal advice. **Needs owner approval of the terms (D5) and ideally a check by the EU adviser
before first use** (master decision 22 adviser batch). Asked **separately** from the gift, **in writing**, only after
the creator has posted. Never assume rights from a tag or a repost.

## 1. Proposed default terms (owner fills or changes every `[ ]`)

| Term | Proposal | Owner decision |
|---|---|---|
| Which content | Only the posts/images/clips listed by URL in the request | [ ] |
| Where | A&W Instagram/Facebook/Pinterest organic posts and autumnandwool.com product pages | [ ] |
| Paid ads | **Separate yes/no box.** Only if ticked. Reuse in ads follows `aw-paid-ads-testing` rules | [ ] |
| Duration | [3 or 6] months from the date of the creator's written yes. Removed from A&W channels after that | [ ] |
| Territory | Online, worldwide (the store ships internationally) | [ ] |
| Credit | "@handle" credited on every organic reuse where the format allows | [ ] |
| Edits | Crop, resize and add text overlays only. No changes to the creator's words, face or body | [ ] |
| Fee | None (gift already sent) / EUR [ ] (owner decision, not in the first 90 days by default) | [ ] |
| Ownership | The creator keeps the copyright. A&W gets a non-exclusive licence for the term above | [ ] |
| Other people in the content | Only if the creator confirms everyone visible agreed (consent form, master decision 6) | [ ] |
| Withdrawal | If the creator asks early, A&W stops new uses within [7] days. Paid ads stop within [ ] days | [ ] |
| Disclosure | Reused content keeps an "ad / partnership" label where the platform needs it | — |

## 2. Request message (owner sends; email preferred so the yes is on record)

```
Hi [first name], thank you again for your post about the [product]. We'd love to share it on our own pages.
Could we use these with credit to @[handle]:
[URL 1]
[URL 2]
Where: our Instagram, Facebook, Pinterest and the product page on autumnandwool.com.
[Ads: only if you agree, also in our paid ads. Yes / No]
For how long: [3 / 6] months from your reply, then we take them down.
We'd only crop or resize, never change what you said or how you look. You keep the copyright.
[Fee: none / EUR __.]
If that's OK, a short reply saying "I agree" to this message is enough. You can ask us to stop at any time.
Thank you, Kristine
```

## 3. Record
Save the creator's written reply (screenshot or email) in the owner's files. In `creator-tracker.csv` set
`usage_rights` = `organic-<months>m-<yyyy-mm-dd>` or `organic+ads-<months>m-<yyyy-mm-dd>`, or `none`. Calendar reminder
for the end date (owner). No asset goes to Growth or Creative without this field filled.
