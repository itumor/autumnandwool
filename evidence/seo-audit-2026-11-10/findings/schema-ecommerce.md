# Schema and E-commerce audit: autumnandwool.com (2026-11-10)

Scope: JSON-LD, microdata and OG product tags in the saved crawl HTML (`crawl/html/`), embedded Squarespace product JSON (variants, SKU, stock), `build_google_feed.py` and the committed feed `autumnandwool-google-feed.tsv`. No live fetching was done. Validator: `claude-seo run schema_ecommerce_validate.py --json` run on each of the 22 extracted Product blocks (local stdin).

Data notes:
- `crawl/html/www-autumnandwool-com.html` is 0 bytes. Homepage JSON-LD was read from `www-autumnandwool-com-home.html` (the /home page, same template).
- Microdata: only `itemprop` meta tags on PDPs (name, url, image, description, thumbnailUrl). No `itemtype` microdata.
- Stock quantities are a snapshot from the embedded product JSON at crawl time, not live.

## Scores

- **Schema / Structured Data: 45/100.** Product blocks are present on all 22 PDPs with the core snippet fields (name, image, price, currency, availability). Data quality is weak: multi-variant products emit AggregateOffer with no price or SKU, every name carries a site suffix, LocalBusiness describes hours and an address that a visitor cannot see, and contact data in Organization differs from the visible contact details.
- **E-commerce readiness: 60/100.** The on-page basics are solid (visible price, size options, measurements, delivery and returns block, 98/98 feed rows match live data). Gaps: feed availability hard-coded to in_stock, feed generator not reproducible from the repo, category pages missing H1 and meta description, no reviews, and an unsourced 4.9-star claim on the homepage.

## What works

- Product JSON-LD on all 22 PDPs (plus gift card): name, image, description, brand, offers (price, priceCurrency, availability). Validator passes `ok: true` on 7/22 (single-offer PDPs), with only Medium/Info items on the rest.
- Visible price in static HTML, e.g. `€155.00` on the dusty pink turtleneck and `€136.00` on the grey lambswool sweater. Size options visible as text (`Size: S M L XL`).
- PDP content: garment measurements per size, `Size Guide` link, `DELIVERY & RETURNS` block ("Free shipping. In-stock items ship from Riga within 2–5 working days. 14-day returns."), consistent with `/faq` and `/shipping-returns` on delivery times and the 14-day return window.
- `og:type="product"` on all 22 PDPs, `og:image` on every page, `product:price:amount`, `product:price:currency`, `product:availability` meta on PDPs.
- Canonicals present on every 200 page and equal to the feed link for all 98 feed rows.
- Feed vs live (98 rows): all 98 SKUs exist in the embedded product JSON; all 98 prices match; all 98 `link` values equal the live canonical; all 98 image IDs appear on their product page.
- FAQ page has no FAQPage markup (correct under current Google policy; no action).
- No `aggregateRating` or `review` markup is present, so no fabricated review rich result is being emitted.
- `/cart` is `noindex`; `/this-page-does-not-exist-404-test` returns 404.
