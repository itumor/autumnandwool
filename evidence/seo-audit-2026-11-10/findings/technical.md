# Technical SEO and Sitemap Audit: www.autumnandwool.com (2026-11-10)

Scope: robots.txt, sitemap.xml, canonicals, redirects and host consolidation, 404 handling, URL structure, duplicates, indexability directives, hreflang/lang, security headers, mobile viewport, JS rendering, internal linking and orphans, IndexNow, structured data (light). Core Web Vitals excluded (PageSpeed agent).

Data used: `crawl/pages.tsv`, `crawl/html/*.html`, plus live requests (homepage with headers, sitemap headers, `/about/`, `http://autumnandwool.com/`, 404 test, `claude-seo run sitemap_discovery.py`, `claude-seo run render_page.py /shop --mode auto`). About 10 live requests in total, all at 1 request/second or slower.

## Score: 70 / 100 (Technical SEO)

Basics are sound: clean 200/404/301 behaviour, one-hop host and protocol consolidation, valid sitemap declared in robots.txt, server-rendered product content, viewport on every page, self-canonicals on products and legal pages. The deductions come from canonical and sitemap conflicts on the category and homepage URLs, missing category metadata and H1s, duplicate product copy, and a thin security header set (platform-controlled).

## What works

- **Robots.txt** (`crawl/html/www-autumnandwool-com-robots-txt.html`): no site-wide Disallow. Blocks are limited to `/config`, `/search`, `/account/`, `/api/`, `/static/` and tracking query parameters. `Sitemap: https://www.autumnandwool.com/sitemap.xml` declared. The AI-bot user-agent lines sit in the same group as `*`, so they get the same (narrow) rules, not a full block.
- **Rendering resources**: `grep 'src="/static/'` on the live homepage returns 0. Scripts and CSS load from assets.squarespace.com and static1.squarespace.com, so the robots `/static/` rule does not block render resources on www.
- **Sitemap validity**: `sitemap_discovery.py` returns `kind: urlset, valid: true`, found via robots.txt. All 39 sitemap URLs return 200 in the crawl. No non-200 or redirected URLs in the sitemap.
- **Redirects and host consolidation**: `http://autumnandwool.com/`, `https://autumnandwool.com/`, `http://www.autumnandwool.com/` each return 301 to `https://www.autumnandwool.com/` (crawl `location` column; live `http://autumnandwool.com/` returns 301). No redirect chains. HSTS present.
- **404 handling**: `/this-page-does-not-exist-404-test` returns HTTP 404 (body contains "not found"), not a soft 404. `/blog` and the single-`p` product slug also return true 404s.
- **Trailing slash**: `/about/` returns 200 with `<link rel="canonical" href="https://www.autumnandwool.com/about"/>`, so the duplicate is canonicalised.
- **Canonicals on content pages**: every product page and legal/info page is self-canonical (e.g. `shop/p/p/...-679428`, `/about`, `/faq`). `/cart` is `NOINDEX` with no canonical (appropriate).
- **JS rendering**: `render_page.py --mode auto` on `/shop`: `mode_used: raw`, `is_spa: false`, 0 console errors. Product names, prices (`"priceCurrency":"EUR"`, `"price":"136.0"`) and category headings are in raw HTML.
- **Mobile**: `<meta name="viewport" content="width=device-width, initial-scale=1">` on every crawled HTML page. Touch targets not assessed.
- **Internal linking**: all 22 product URLs are linked from `/shop` raw HTML (depth 2 from `/`). Each product has at least 3 inbound internal links from crawled pages.
- **Images**: 0 `<img>` without an `alt` attribute across crawled pages (`img_no_alt` in pages.tsv is a different count; see caveats).
- **Structured data presence**: Product JSON-LD with name, image, brand, offers (`availability: InStock`, price) on all 22 product pages. Organization and LocalBusiness on every page.
- **Language**: `<html lang="en-US">` on all pages.
- **hreflang**: none present. Not required for a single-language store; becomes relevant only if other-language versions are built.

## Caveats on the crawl data

- `crawl/pages.tsv` meta_desc column is truncated at apostrophes (`women's`, `Wool's`). The two affected rows showed "Lightweight women" and "Explore Autumn & Wool" (desc_len 17 and 21). Raw HTML has the full text (130 and 158 characters). Those were false positives and are not findings. Only these two rows mismatch raw HTML (cross-checked all 44 200-status pages). Fix the export before reusing the TSV.
- `crawl/html/www-autumnandwool-com.html` (the root `/`) and `autumnandwool-com.html` are 0 bytes. The homepage analysis uses a live fetch saved to scratchpad (`home-live.html`) and the `/home` file, which are identical in title, meta description and canonical target.
- pages.tsv `img_no_alt` (4 on the homepage) counts differently from the HTML `alt` check (0 missing `alt` attributes). Likely empty `alt=""` values on decorative images; not checked individually.
