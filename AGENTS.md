# AGENTS.md (autumnandwool)

Working repo for Autumn & Wool (Squarespace 7.1 e-commerce + business operating system). Mostly Markdown/CSV; active dev is in `plans/2026-2027/` and `business-os/`.

## Repo map
- `README.md` - store overview and directory map.
- `PROJECT-HANDBOOK.md` - hard-won live-site facts, blockers, and open owner items. Read this before touching Squarespace.
- `business-os/` - company planning, owner questions, SOPs, assumptions registers (`.../assumptions-wave3.md`).
- `plans/2026-2027/` - department plans and status files.
- `plans/2026-2027/status/` - task tables + `OPEN-TASKS.md` rollup.
- `campaign-assets/drafts/` - seasonal plan/copy drafts by wave.
- `build_google_feed.py`, `unit_economics.py` - the only executable scripts.

## Working rules
- No test suite, lint, or CI in this repo. Verify product changes with Markdown diff / planned CSV regeneration only.
- Status rollups and task counts are generated by `rollup.py` per `OPEN-TASKS.md`; if that script is unavailable, edit tables carefully and keep these four numbers aligned: assumed, blocked, to-do, done.
- Never assume owner-provided numbers (stock, costs, measurements, carriers). `ASSUMED` tasks exist for those and hold placeholder `[FILL]`.
- Prefer evidence over narrative: screen captures, public CSS checks, and live snapshot output live under `evidence/`.
- Squarespace plan gates mean no Code Injection, inline `<script>`, or waitlists. Working layers are Custom CSS, product metadata, Merchant Center, and the custom CSS/checkout patches already shipped.

## High-signal gotchas
- Squarespace product pages, category pages, checkout, and merchant feed are subject to plan limits; do not propose JavaScript injections.
- Waitlists and some marketing blocks are gated as well.
- The 2026-10-19 overlay incident (`.sqs-widgets-confirmation-overlay`) must be treated as a load-bearing guard: Custom CSS must keep `pointer-events:none !important;` on those selectors.
- Never edit seller content from `/Users/eramadan/autumnandwool` without the planned copy; keep owner decisions in the A-* assumption IDs and the `owner-inputs-wave2.md` unblock pack.
- Old worktrees live under `.claude/worktrees/`; avoid changing through them unless explicitly asked.
