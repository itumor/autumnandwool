## Shoot set-up (both parts)

| Item | Spec |
|---|---|
| Shot type | #1 variant flat lay, directly above, garment fills 75-90% of frame |
| Location / light | Studio window, indirect daylight, roughly 10:00-14:00 `[VERIFY: best window time in the Riga studio]`. Turn off room lights (no mixed light) |
| Background | Plain oat/off-white paper or sheet. For Melange Beige, Light grey, Beige: light grey background so edges show |
| Colour reference | White paper or grey card in the first frame of each colour; set white balance from it |
| Prep | Steam, lint-roll, check loose threads and pilling. Do not hide real flaws; set aside a piece that has one |
| Camera | Phone is fine (owner pack A). Highest resolution, no filter, no portrait mode, HDR off if it shifts colour |
| Export | JPG, 2000 px long edge minimum, 4:5 crop for PDP plus untouched original kept |
| Not allowed | Text, logos, watermark, price, borders, props, recolouring, AI fill of any garment area |
| Allowed edits | Exposure, white balance, crop, straighten, dust/lint and background marks |
| People | None for this brief. On-body shots come later and need consent (owner decision 6) |
| Folder | `campaign-assets/photos/variants/YYYY-MM-DD/` `[VERIFY: owner's preferred folder or Drive]` |
| Who uploads | **Owner** in Squarespace: Products -> {product} -> Inventory -> Variants -> EDIT ALL -> variant -> Upload variant image. Agents never edit products or the feed |
| Owner time | Part A about 50 min (11 x 4-5 min); Part B about 60 min (13 colours). Fits inside one 2-hour session each (see `shot-list-2026-10-27.md`) |

True-colour check before upload: hold the garment next to the screen in daylight. If the photo colour does not match,
fix white balance only. If it still does not match, reshoot. Never shift hue.
